CONE BATTLE – iOS / Android / PC (mit ORIGINALGRAFIKEN)
===================================================

Dies ist eine Browser-Portierung des MATLAB-Spiels Cone_Battle_V2.m.
Die originalen Bilder TUG.png, HM.png und Cone.png sind enthalten.

SPIELEN
- Spielfeld 20 × 30 Felder; Zug alle 0,20 Sekunden.
- Zwei Spieler auf EINEM Gerät, beide mit Touch-Steuerung.
- PC: TUG Racing = WASD, municHMotorsport = Pfeiltasten.
- Spielstart/Neustart per Button, zusätzlich Leertaste / R.
- Pylonen sammeln, Spuren wachsen lassen, Kollisionen vermeiden.
- Kein Online-Multiplayer auf zwei getrennten Smartphones.

AM COMPUTER TESTEN
Die Datei index.html im Browser öffnen. Die Bilder werden zusammen
mit der HTML-Datei aus demselben Ordner geladen.

PER WHATSAPP VERSCHICKEN – ALS LINK
1. Das ZIP-Archiv entpacken.
2. Alle Dateien aus dem Ordner (nicht nur index.html) in ein öffentliches
   GitHub-Repository laden, z. B. "cone-battle".
3. In Settings > Pages > Build and deployment die Veröffentlichung
   aus branch "main" und Ordner "/ (root)" wählen.
4. Den GitHub-Pages-Link via WhatsApp versenden.

OFFLINE AUF iOS
1. Die Webseite bei bestehender Internetverbindung in Safari öffnen.
2. Über Teilen > Zum Home-Bildschirm hinzufügen.
3. Die Seite einmal vollständig laden lassen; der Service Worker speichert
   die HTML-Datei, Icons und alle drei Bilder für Offline-Nutzung.
4. Danach sollte die installierte Web-App ohne Netz funktionieren.
   iOS kann Browserdaten bei Speicherknappheit löschen; dann erneut
   online öffnen.

WICHTIG: Die Installation/Offline-Cache-Funktion benötigt eine per HTTPS
bereitgestellte Webseite (z. B. GitHub Pages), nicht nur file:// oder das
Verschicken einer einzelnen HTML-Datei als WhatsApp-Anhang.
